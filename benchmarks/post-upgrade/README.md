# HP 250 G8 Post-Upgrade Measurements

## Memory Upgrade

The HP 250 G8 was upgraded from 8 GB of DDR4 memory to 16 GB by
installing an additional 8 GB Crucial DDR4-2666 SO-DIMM.

| Post-upgrade item | Result |
| --- | ---: |
| Installed RAM | 16 GB |
| Usable RAM | 15.8 GB |
| RAM in use | 6.2 GB |
| RAM utilization | 41% |
| Available RAM | 9.4 GB |
| Memory speed | 2667 MT/s |
| Memory slots used | 2 of 2 |
| Form factor | SODIMM |
| Hardware reserved | 218 MB |

## Baseline vs. Post-Upgrade

| Measurement | Baseline | Post-upgrade |
| --- | ---: | ---: |
| Installed RAM | 8 GB | 16 GB |
| RAM utilization at capture | 71% | 41% |
| RAM in use | 5.5 GB | 6.2 GB |
| Available RAM | — | 9.4 GB |
| Memory slots populated | 1 of 2 | 2 of 2 |
| Memory speed | — | 2667 MT/s |

## Result

The memory upgrade doubled installed system memory from 8 GB to 16 GB.

At the time of the post-upgrade measurement, Windows reported 9.4 GB
of available memory and 41% memory utilization, compared with 71%
memory utilization in the baseline capture.

These measurements are observational Task Manager snapshots rather
than controlled synthetic benchmark results.
